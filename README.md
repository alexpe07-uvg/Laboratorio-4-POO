## Instrucciones para compilar el programa
Para compilar todos los archivos del proyecto, abre la terminal en la carpeta principal y ejecuta:
`javac *.java`

## Instrucciones para ejecutar el programa
El sistema cuenta con dos modos de ejecución:
- **Menú Interactivo:** Ejecuta `java Main` para iniciar el menú principal.
- **Pruebas Automáticas:** Ejecuta `java PruebasSistema` para verificar los casos de prueba de las reglas de negocio.
